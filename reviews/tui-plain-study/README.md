# A / Plain — 默认终端样式

A「留白」已经替换原有默认 TUI。`index.html` 是设计阶段的网页场景稿；实际运行和下面的渲染导出使用真正的 Kroma / Ratatui。

## 启动

安装最新版本后，直接在真实终端运行：

```powershell
kroma
```

恢复最近会话：

```powershell
kroma --continue
```

不再需要设置 `KROMA_TUI_STYLE`，旧变量不再参与样式选择。无需改写用户配置或迁移会话。

从源码启动：

```bash
cargo run --locked
```

原有 `scripts/preview-plain.ps1` 保留为兼容启动脚本，只负责增量编译并启动默认 TUI，不再设置环境变量。

## 当前布局

- 中性灰阶主体，采用 S2 语义色：状态符号和短状态词一起着色，命令、日志、正文与输入仍保持灰白。状态色已提高辨识度，但仍满足正文对比度。
- 单列、全宽工作区；正文、代码、表格与工具输出都在消息底色内排版，不再设置固定阅读列。旧 `/layout` 偏好仍可读取，但不会收窄 Plain 的消息文字。
- 消息灰底右侧与滚动条之间保留 3 栏终端底色接缝，形成可见的右侧安全边距；正文在灰底内排版，右缘就是安全边界。代码复制标签与 `[检视]` 停在灰底内，不进入接缝。
- 无会话顶部栏；低对比 `YOU / KROMA` 标识角色，中文界面为 `你 / KROMA`。
- 用户消息和 Kroma 回答使用相同的灰底（深色主题 `#1B1B1B`），不受 `/layout` 模式限制；灰底不铺到滚动条，右侧 3 栏接缝始终可见。
- 用户消息保留上下各一行内留白；用户竖线为紫罗兰，Kroma 竖线为青绿，两者使用同一 `▎` 字形与正文起始列。一次 Kroma 回合只出现一个 `KROMA` 标签，青绿竖线连续贯穿正文、思考、工具记录、代码与完成状态。
- 等待模型时的 `连接中 / Connecting` 状态不再并入用户消息：用户块结束后保留一条终端底色分隔行，状态行独立使用 Kroma 青绿竖线。已有助手内容后的活动状态仍留在当前回合内，保持竖线连续。
- 回合之间保留一条终端底色分隔行，不铺消息灰底、不带竖线，避免下一个用户消息看起来嵌在上一轮 Kroma 里。角色色独立于 S2 状态色，不表示成功或失败，也不与运行中的蓝色重复。
- 竖线、底色、角色标题属于绘制装饰，不进入复制文本。浅色主题使用对应灰底和深色竖线；原生 `mono` 不强制 RGB。
- 开放式输入区，一条顶部细线，不铺独立输入底色；空草稿不显示占位口号。
- 硬件光标沿用真实编辑器坐标；保留多行编辑、选择、输入历史等功能。
- 每次工具调用保留独立记录，相邻调用不再合并或隐藏。成功记录压缩为一行：语义状态符号 + 有效命令段（非 shell 工具显示名称/参数）；不再显示右侧展开角标，点击左侧状态符号即可展开；不再重复 `Shell · Inspect · Done` 之类的类别与完成词，成功记录的亚秒耗时也隐藏。成功时收掉 `cd … &&`、分隔用 `echo` 等外壳，只保留真正执行的命令段；展开后仍显示完整原始命令。执行中、失败、警告和结果未知才显示着色状态词、有意义的耗时与有限输出预览。
- 工具记录嵌在 Kroma 回合的竖线内，记录与正文同列。成功记录直接使用消息灰底，不额外铺面板；只有执行中、失败、警告或未知记录才铺一层中性强调面。记录之间不插入空行，命令本身承担分隔；命令在右缘前统一截断，不绘制展开角标，展开后显示完整 Command/Output（`Ctrl+O` 展开全部）。
- 仅失败与结果未知的记录在右侧提供 `[检视]`；成功记录保持安静。
- 工具输出中的 ANSI 转义序列在显示时剥离，其余控制字符显示为可见占位符；原始结果和发送给模型的记录不变。
- 信息栏左侧为模型和思考等级，右侧为上下文用量 / 总容量及最近一次主请求的缓存命中率。仅上下文风险读数着色，缓存和其他字段不染色。
- 未知值为 `—`，估算带 `~`；后台标题和摘要不覆盖主请求读数。
- 首页、角色、命令选择器与编辑器保持统一灰阶。链接仅在悬停时显蓝；已识别的 diff 只给增删标记用色，不染整行代码。

`dark` 为近黑，`light` 为银白，`mono` 尊重终端原生前景和背景。F2 和 `/theme` 继续切换预设。仅启动不会保存或覆盖用户配置；手动修改主题时仍按原有流程保存。

为保持统一基础灰阶与 S2 语义层级，旧主题的逐色覆写、插件彩色覆写和自定义活动动画不应用于默认界面；已有配置仍保留，工具标签、插件命令和业务能力不变。语义色独立于全局 accent，不会将输入提示符或代码关键字一起染色。

详细色值和规则见 [S2 语义色规范](../tui-semantic-colors/README.md)。

## 保持不变的行为

- Agent Loop、模型请求、工具执行和会话格式。
- Enter、换行、取消、引导和排队语义。
- 运行中普通文字 Enter 仍引导当前任务；显式 `/queue` 用于后续任务。这次替换不是此前 RUN2 的交互改造。
- 附件存储、传输、编辑与磁盘文件所有权。
- 现有语言、布局、模型和主题配置文件，不自动迁移或重写。
- `kroma --no-tui` 仍进入原有行式 CLI，不是旧版 TUI 的样式开关。

旧渲染器的底层初始化仅保留用于历史回归测试；正常交互入口无条件使用 `UiState::new_default`，没有预览开关。

## 不调用模型，导出默认渲染器的结果

```bash
cargo test --locked export_plain_preview -- --ignored --nocapture
```

输出：

```text
reviews/tui-plain-runtime/index.html
reviews/tui-plain-runtime/*.ansi
reviews/tui-plain-runtime/*.txt
```

通过真实 `UiState::new_default` 和 Ratatui `TestBackend` 生成，覆盖日常问候、首页、短对话、执行中、失败、警告、代码差异、普通代码、选择器和执行检视，包含 80×24 / 120×36、近黑 / 银白。无需模型凭据；不是交互终端录屏。

测试：

```bash
cargo test --locked tui::view::plain_tests
cargo test --locked
```
