# Project memory contract

The current contract is maintained in [docs/project-memory.md](../../../docs/project-memory.md)
and the [plugin README](README.md), not in a second copy of retired P0 behavior.

- API 2 `provide_context`; four model tools and `/memory` inspection/edit controls.
- Host-bound project identity and actual current-human quote verification.
- Rules use original wording; no automatic task-finished promotion or task-history capture.
- Complete recall records with transparent omissions; durable storage has no rule-count quotas.
- Explicit reversible forgetting, complete live-database purge, durable transactions.
- Review notes remain unverified and accessible when evidence changes.

Predecessor research and interfaces are retained as non-normative
[historical design records](../../../docs/project-memory-history.md).
