# Kroma CLI (`kroma-cli`)

**Kroma** is a next-generation prismatic microkernel coding agent harness written in Rust (~4.2ms cold start, `openat2` / Windows Job Object sandbox, content-addressed `SnapshotStore` with 3-state `--undo`, evidence-linked context projection, incremental SHA-256 `RepoGraph`, Best-of-N isolated worktree tournaments, and the borderless **Kroma Zen** TUI).

## Quick Install

```bash
# Install globally from npm registry:
npm install -g kroma-cli

# Or install directly from the standalone all-in-one tarball:
npm install -g ./kroma-cli-1.5.0-standalone.tgz

# Launch interactive Kroma Zen REPL:
kroma
```
