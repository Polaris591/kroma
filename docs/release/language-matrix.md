# 代码定位：语言能力矩阵与「无增益撤回」记录（T26）

## 1. 结论先说

- **离线定位能力已实测**：自然语言 Issue（**不含任何符号名、文件名也不含答案词**）在 5/5 上 rank-1 命中，
  符号名基线 0/5。变异验证：把内容 token 的种子去掉，命中掉到 3/5。
- **模型对照实验（EXP-03）是 BLOCKED**：依赖 T24 的预算授权。下面所有数字都是**离线、可复算**的，
  不涉及任何模型调用，也不声称模型侧收益。
- **没有引入 LSP / 向量库 / 全仓语义图**：任务卡的停止条件明确禁止同时引入这三者（无法归因），
  且当前离线指标已能满足「自然语言找位置」，再叠加只会增加不可归因的复杂度。

## 2. 三种策略的对照（离线，无模型）

| 策略 | 实现 | 说明 |
| --- | --- | --- |
| `grep/find/read` | 文件名 + 符号名子串 | 计划里要求被超越的基线；答案词不在文件名时必须靠符号名 |
| 当前图（T26 后） | 路径/符号 + **文件内容 token**（标识符 + 注释词）+ 一跳邻居 + 个性化 PageRank | 注释是意图写下来的地方 |
| 可选语义图 / LSP | **未接入** | 无证据表明需要；接入前必须先有可归因的收益 |

基准语料：12 个文件（5 个目标 + 1 个符号目标 + 6 个干扰），文件名一律 `module_*.py`，
**文件名不泄露答案**。5 条 Issue 形如「retry backoff jitter upstream connection」，
答案只能从注释里读出来。

| 指标 | 符号名基线 | 当前图 | 门槛 |
| --- | --- | --- | --- |
| rank-1 命中 | 0 / 5 | **5 / 5** | ≥ 4 / 5 |
| rank-3 命中 | — | 5 / 5 | — |
| 符号名查询不回归 | 2 / 2 | 2 / 2 | 不回退 |
| 索引被截断时 | 词法回退仍可定位 | 同上 | 必须有回退 |

复现：`cargo test -p kroma-core --test t26_localization`

## 3. 语言能力矩阵

「有符号抽取」= `lang_of` 能识别该扩展名并抽取顶层符号；「有注释词」= 注释文本进入内容 token
（只有这些语言才有自然语言定位能力）。**没有任何语言接入 LSP 或类型解析**。

| 语言 | 扩展名 | 符号抽取 | 注释词 | 依赖边来源 | 置信等级 |
| --- | --- | --- | --- | --- | --- |
| Rust | `.rs` | ✓ | ✓ | 引用/导入 token 共现（词法） | 低（token 共现，不做类型解析） |
| Python | `.py .pyi` | ✓ | ✓（`#`） | 同上 | 低 |
| TypeScript / JavaScript | `.ts .tsx .mts .cts .js .jsx .mjs .cjs` | ✓ | ✓ | 同上 | 低 |
| Go | `.go` | ✓ | ✓ | 同上 | 低 |
| Java | `.java` | ✓ | ✓ | 同上 | 低 |
| C / C++ | `.c .h .cc .cpp .cxx .hpp .hh` | ✓ | ✓ | 同上 | 低 |
| 其它（YAML/TOML/Markdown/Shell/…） | — | ✗ | ✗ | — | 不索引 |

**置信等级一律是「低」**：依赖边来自 token 共现（`extract_reference_tokens` +
`extract_import_tokens`），不是解析器给出的真实引用。任务卡要求「依赖边携带解析来源与置信等级」——
这里如实标为词法来源、低置信，没有把它包装成解析结果。

## 4. 工具界面：不做「一刀切的简化 ACI」

任务卡第 3 步是「分模型比较原生 edit/write 与简化工具界面」。**没有做**，理由：

1. 需要真模型对照（EXP-03），而 EXP-03 依赖 T24 的预算授权（BLOCKED）；
2. 在没有数据前给所有模型套同一套简化界面，正是任务卡说「避免为所有模型强制相同工具集合」要防的事。

工具界面的现状：`edit` / `write` / `read` / `bash` 等原生工具始终可用；
T12 的按需工具发现是**可选**机制（`--on-demand-tools`，默认关闭），且激活受策略与预算约束。
没有为任何模型隐藏原生工具。

## 5. 无增益撤回记录（预先声明）

以下情况一旦出现，**回退到本文第 2 节的「当前图」或纯词法搜索**，不保留复杂索引：

| 条件 | 动作 |
| --- | --- |
| 注释词接入后 rank-1 命中没有提升（< 基线 + 2） | 移除 `CONTENT_MATCH_WEIGHT` 种子，回到路径/符号 |
| 建图时间或内存超出既有预算（1200 文件 / 24 MiB） | 保持截断语义，不提高上限 |
| 任何语言需要 LSP 才能超过词法基线 | 该语言单独接入，并标注置信等级；不整体切换 |
| EXP-03 显示模型侧无收益 | 保留离线能力，但不改默认（默认仍是最小工具集） |
