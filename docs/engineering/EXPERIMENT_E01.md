# E01：完整能力的存在税

三视角实测，数据 `/opt/kroma-v4/evidence/e01/`。

| 视角 | 测法 | 结果 |
|---|---|---|
| 存在 | 三暴露 × 5 次空闲 PSS | 臂间差 324 KB vs 臂内 8 027 KB → 噪声内，无驻留税 |
| 使用 | 双臂配对 bench（gpt-6-luna，6 任务） | 质量 0.0pp；token 差跨零；**TTFT 14 040 ms vs 3 568 ms**，墙钟 589 s vs 178 s |
| 恢复 | SIGTERM 后 PSS 采样 + 空闲 CPU tick | 释放时间 0.0 s，空闲 0 tick → 无平台期、无唤醒 |

结论：未使用能力不占内存、不占空闲 CPU、取消即释放；成本出现在请求 prefill 上，
表现为首 token 延迟（约 4 倍）。因此"关掉用不到的 schema"买到的是**响应速度**，
不是内存或 token——这条直接影响该怎么向用户描述这个开关。

限制：6 个任务簇、1 次重复，延迟差异只有点估计与墙钟，不做统计主张。
