# E04：工具暴露的经济性

三臂 + 留出集确认，数据 `/opt/kroma-v4/evidence/e04/`。

| 阶段 | direct | deferred | codemode_only |
|---|---|---|---|
| dev（6 任务） | 1 000 429 tok | 560 819（−44%） | 723 679（−28%） |
| 留出集（2 任务） | 175 946 tok | 209 378（+19%） | 177 409（+1%） |

质量三阶段全为 0.0 pp。

结论：效应**不复制**——dev 说便宜、留出集说更贵，更早的两臂 dev 说无差异。工具暴露方式
对 token 的影响被噪声主导，不足以改默认值，`on_demand_tools` 与 `codemode` 保持默认关闭。

这条结果的价值在于方法：没有留出集确认，我会把 dev 的 −44% 当成产品改进推上去。
预注册 + 一次性留出集在这里直接否掉了一个假阳性。

副产物：`codemode` 工具本身（`tool/codemode.rs`）是这一臂逼出来的真实现，工作区受限、
与 bash 同策略、走同一执行器。
