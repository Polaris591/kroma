# E08：有界自治（路由接线）

数据 `/opt/kroma-v4/evidence/e08/`。

路由从「只有单测」变成运行路径里每轮观察一次的真实决策者，信号是测出来的（本轮工具返回字节、
工具错误率），决策权只有一个：是否允许动用昂贵策略。决策逐条进 run summary 与 bench 报告。

| 臂 | 通过 | token | 决策数 | 升级次数 |
|---|---|---|---|---|
| routing_off | 2/2 | 1 025 415 | 0 | — |
| routing_on | 2/2 | 1 734 645 | 73 | 0 |

三条实测结论：接线生效且可观测；73 次决策零切换（滞回在真实负载上不抖动）；当前阈值下
路由在这类任务是惰性的（复杂度从未越过 0.7，13 轮被低置信否决）。

两臂行为等价而 token 差 69%（CI 跨零）——这是运行间方差，不是路由效果。这组实验最大的
收获反而是这个：噪声量级和我们一直在测的效应同阶，之前所有 inconclusive 判定都因此站得住。
