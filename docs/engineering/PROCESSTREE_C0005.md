# C00-05：休眠/唤醒/释放的进程树成本

测量脚本 `scripts/measure-process-tree-cost.py`，用 `kroma serve` 起完整守护进程后保持空闲，
不产生模型调用。数据 `evidence/c00-05/process-tree-cost.json`。

| 规格 | 测量 | 结果 |
|---|---|---|
| 未使用能力不创建大索引/worker | 空闲守护进程 6 周期，子进程数与 workspace 写入字节 | 0 / 0 |
| 共享依赖释放不终止其他 run | 两个守护进程共享二进制与宿主缓存，释放其一 | 另一个仍存活且端口可连 |
| 反复启停内存进入有界平台期 | 6 次启停的进程树峰值 PSS | 前半 18 618 KB → 后半 18 615 KB（−2 基点） |

这条与 E01 的关系：E01 量的是"同一进程内不同暴露的驻留成本"，C00-05 量的是"整个守护进程的
启停与释放成本"。两者都指向同一结论——未使用的能力不预先付费。
