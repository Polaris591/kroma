# Desktop 前端设计审查与修复记录

## 范围与原则

本轮检查的是当前工作树，不是纯净 HEAD。已有的大量前端改造予以保留，没有回退旧布局，没有修改 Rust Agent、模型协议、插件权限或会话存储实现。

走查了 `desktop/src/components` 下的 34 个 Svelte 组件、`App.svelte`、全局样式与主题变量，并通过真实 Svelte 页面、合成 Desktop Host 和安装在本机的 Edge 检查交互。合成宿主不读取私人会话、真实密钥，不调用模型、不启动 MCP 或插件进程。

设计判断以阅读与输入是否顺畅、状态是否诚实、失败是否能恢复、键盘是否可用、窗口变小时是否仍保留控制权为准。不把“换一种样式”当成改进，也不宣称存在适用于所有用户和设备的绝对最优设计。

后续按用户对质感与配色的要求，继续实施了中性色主操作、石墨底色、少量灰紫提示和分组设置布局。当前视觉规则与这一阶段的细节见 [Desktop 视觉与交互基线](desktop-visual-system.md)。下方验证结果包含这一阶段，不再只是最初的功能修复。

## 覆盖清单

| 区域 | 已走查的组件 | 本轮结论与处理 |
| --- | --- | --- |
| 窗口与导航 | App、Topbar、SessionSidebar | 保留桌面单行标题栏；窄窗拆分窗口操作与模型控制。低频导出/备份/导入合并到“会话操作”，不删除能力。侧栏抽屉使背景 inert，约束 Tab 范围，关闭时返回入口，导航后收起。普通会话标题不再一直为隐藏操作预留整块宽度；置顶按钮保持固定位置，避免悬停移位误点。Shift 范围选择遵从实际显示顺序。 |
| 消息与过程 | ChatTranscript、TranscriptTurn、LiveTimeline、ToolDetail | 保留正文与按需展开的过程。空会话同步中不再提前显示可操作的欢迎页。实时阶段独立播报，计时器更新不再使整个状态行每秒重复播报。 |
| Markdown | Markdown、StreamingMarkdown | 保留净化、HTTP(S) 链接拦截、精确代码复制与流式节流；代码滚动区可由键盘进入。未新增渲染器或语法高亮依赖。 |
| 输入与后续任务 | ComposerPanel、AskBar | 输入高度受窗口和插件行数共同约束；展开队列可收缩滚动，保留最小对话空间与停止控制。文件建议改为输入区上方浮层，不再挤占布局高度；补充输入框与选项的辅助技术关联。输入法组合期间方向键不改变建议。附件达到上限明确提示，保留任务运行期间为后续任务准备附件的既有行为。 |
| 模型配置 | SettingsView、UnifiedSettings、AddModelDialog、ModelPicker、ThinkingPicker | 保留草稿、仅保存/连接/设默认的区别。仅保存也执行 URL、必填与数值范围校验；可撤销未保存修改。新增模型连接中锁定字段与协议，失败保留输入。多模型列表限制高度，窄窗高级字段单列显示。模型与思考仍共用一个面板。 |
| 逐项能力 | CapabilitySettings、AbilitiesDialog | 保留每项默认值、会话三态和搜索后的批量范围。统一搜索与选择控件外观。能力清单与当前会话设置仍是独立语义，不合并成含混的总开关。 |
| 上下文与用量 | ContextMeter | 不再从配置容量反推占用。缺少报告显示未知；剩余输入同时受模型输入上限与输出预留约束。环形图可封顶，但文字不隐藏超限。浮层聚焦、Escape、外部点击及叠加能力弹窗均有明确焦点归属。运行中禁用手动压缩并说明原因。 |
| 插件管理 | PluginsView | 密钥字段改为 password；失败不清除输入，成功后清空。操作串行并有状态反馈，开关保存失败恢复真实状态。卸载失败留在确认框中，不再假装成功。仅查看普通字段不产生无意义保存。 |
| 插件展示 | PluginDesktopFrame、PluginWidgets、PanelBlocksView | 保留 iframe 沙箱、原有桥接与所有展示位置。加载失败可原地重试；旧请求不再向已更换的 iframe 回写。进度条改为实际可绘制的块级填充并提供可访问数值；多行键值对使用网格排布。 |
| 附件 | AttachmentImage、AttachmentPreviewDialog | 保留按需读取、格式与解码失败反馈、Blob URL 回收、迟到读取隔离及只读预览。不把图片预览变成文件编辑器。 |
| 文件差异与回退 | WorkspaceChanges、TurnChanges、RewindDialog | 空差异显示明确的空状态；读取失败可重试，复制失败明确反馈。差异滚动区可由键盘进入。文案说明快照对比也可能包含其他程序的同期修改，避免把全部变化归功于模型。保留只回退对话与同时还原文件的区别。 |
| 提示与确认 | AppBanner、DeleteConfirmDialog、CloseConfirmDialog、BackupImportDialog、BackupExportDialog | 错误关闭按钮有明确标签；窗口命令失败显示给用户。保留破坏性操作的安全初始焦点、忙碌中不可关闭和失败后的重试路径。长按钮组可换行。导入与可恢复备份不冒充 Markdown 导出。 |
| 辅助入口 | StorageDialog、KeyboardShortcutsDialog | 保留本机数据清理、部分失败反馈、运行中保护、F1 和快捷键说明，不增加新的常驻工具栏。 |
| 全局呈现 | app.css、tokens.css | 默认使用石墨画布、中性主操作和少量灰紫提示，不再使用绿色承担品牌、运行与启用等多种角色。保留插件颜色契约，适配浅色与自定义强调色的可读文字、原生控件和语义色。统一控件、焦点、表面、小窗口与系统高对比度状态；浮层只有轻微透明度入场，尊重减少动态效果偏好。 |

## 回归检查

新增 `desktop/tests/design-review-ui.mjs`，覆盖本轮设计修复的 13 组真实页面交互，包括：

- 会话操作菜单、重命名和焦点返回。
- 非提交式保存按钮的校验与草稿撤销。
- 模型连接中锁定输入与失败恢复。
- 插件密钥保存、失败开关回滚及卸载失败。
- 上下文未知值、独立输入上限、嵌套弹窗。
- 空差异、失败重试和键盘滚动。
- 插件进度显示、键值排布、独立页面加载重试。
- 380px 宽度的标题、浮层、导航抽屉与设置。
- 780×560 的长输入、展开队列、文件建议及输入法方向键。
- 草稿保留和减少动态效果偏好。

新增纯函数与行为测试：`context-display.test.ts`、`popover.test.ts`；会话命令测试补充插件失败必须向调用者传播的断言。

旧浏览器检查中同时修正了几个与当前契约不一致的断言：快捷键入口不等于第二个设置入口；草稿已经使用 v2 JSON；发送调用辅助函数已经返回扁平参数；分组折叠检查必须限定到所选分组；任务运行期间的附件归属于后续草稿。没有为了通过测试而删除原有功能或放松生产保护。

## 本轮验证结果

- `npm run check`：0 errors / 0 warnings。
- `npm test`：31 个测试文件、198 项单测通过。
- `npm run build`：生产构建通过。
- 浏览器：15 套检查全部通过，各套均使用独立 Edge 上下文；没有未捕获的页面错误。其中基础设计检查覆盖 13 组交互，视觉打磨检查另有 7 组；既有附件、并发会话和完整工作流检查也全部执行。
- 截图：复核了 1280×850、780×560、380×700 的聊天、空白会话、模型、能力与插件设置，以及菜单和弹窗；包括浅色主题，检查控件与页面的横向越界。
- `git diff --check -- desktop/src desktop/tests`：通过。

## 验证边界

浏览器检查涵盖真实前端与合成 IPC，不代表真实 Tauri 窗口、系统文件对话框、实际中文输入法、真实模型、真实插件进程或跨平台系统集成已经验收。没有关闭、替换或重启用户正在运行的桌面窗口，没有制作或发布安装包。

本地截图与运行日志保存在被忽略的 `.playwright-mcp/frontend-audit/` 与 `.playwright-mcp/surface-polish/`，仅使用合成数据，不进入生产代码。
